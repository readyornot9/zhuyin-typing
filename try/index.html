      打字

      注音鍵盤
      標準（大千）排列，跟微軟注音一樣
      一聲
      空白鍵
      微軟打法
      預設開啟：一個字要按聲調或空白鍵才算打完；還沒打完前，打錯的注音直接重按就換掉（ㄊㄨㄢ 再按 ㄍ → ㄍㄨㄢ），ㄜㄇ˙ 打反也會變成 ㄇㄜ˙。開頭單打聲母加空白會打出注音符號本身（ㄏ空白 → ㄏ）
      不打聲調
      關掉微軟打法時：直接打下一個字的注音，會自動猜
      只打聲母
      關掉微軟打法時：ㄉㄐㄏ → 大家好。最後一個字也會先猜好，打完直接按 ↓ 改字或 Enter 送出；按空白鍵則是結束這個音、繼續打
      補聲調
      沒打聲調的字，之後再按聲調鍵就補上
      送出
      Enter，或直接打標點

      選字

      打開選字
      ↓
      空白
      字打完聲調後按空白鍵：送出並打出一個空白
      打出注音
      從聲母開始一個一個加空白：ㄏ空白 ㄠ空白 3 → ㄏㄠˇ（ㄏ空白ㄏ空白 → ㄏㄏ）。任何字打完按空白、再按聲調鍵，也會變成注音：ㄨㄛ空白 3 → ㄨㄛˇ。或打完字按 ↓，第一頁最後一個也是注音
      字後加聲調
      打好聲調的字後面再按聲調鍵：我（ㄨㄛˇ）再按 3 → 我ˇ
      簡拼
      前面已經有字才會猜：我（ㄨㄛˇ）接 ㄏ空白 → 我會
      改中間的字
      先按 ← → 移到那個字前面，再按 ↓
      選擇
      數字 1–9，或 ↑↓ 加 Enter，或滑鼠點
      翻頁
      空白鍵／→ 下一頁，← 上一頁
      學習
      你選過的字會記住，下次在同樣的前後文自動選對
      AI 複審
      停下來約 0.15 秒，神經網路會從前 5 個候選句挑最通順的，組字區閃一下代表它幫你改了字；按 Enter 送出前也會先複審

      中英與符號

      切換中英
      單按一下 Shift，或 Ctrl＋空白鍵
      大寫英文
      Shift＋字母，不用切換
      中文標點
      按住 Ctrl：Ctrl＋, . / ; ' 是 ，。？：、（全形；在 ` 符號面板），Ctrl＋[ ] 是『』，Ctrl＋1 9 0 是 ！（），Ctrl＋6 是 …，Ctrl＋- 是 ——
      不用按鍵
      ' 是「、」，[ ] 是「」
      半形符號
      按住 Shift：跟英文鍵盤一樣，! @ # ( ) < > ? : " { } | ~ 等等（其他全形符號在 ` 符號面板）
      符號面板
      ` 鍵打開，Tab 換類別，數字選
      數字
      右邊的數字鍵盤直接打數字
      聲調符號
      沒在打字時單按 3 4 6 7，打出 ˇ ˋ ˊ ˙
